# Quadrangulate_Blender

Tested in Blender version 5.2.2
Not tested on other versions

1. Copy the code from the script file and paste it into the Scripting tab in Blender.
2. Select the desired mesh.
3. Run the code.

The script may produce some minor inaccuracies during mesh cleanup, but it saves time. It is very similar to the Quadrangulate tool in Maya.
